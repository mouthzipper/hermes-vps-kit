# Security policy

Please report security vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/mouthzipper/hermes-vps-kit/security/advisories/new).
Do not post vulnerabilities, credentials, server addresses or client details in public issues or pull requests.
Include the affected revision, reproduction steps and impact. Keep examples generic and remove secrets.

This kit installs autonomous agents that can execute code with the agent user's permissions. Review upstream installers, pins and skills before deployment. Keep privileged administration separate from agent work.
